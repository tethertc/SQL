Технология: MongoDB.

Как проверить:
1. Открыть сайт mongoplayground.net
2. В левое окно (Documents) вставить данные из authors.json
3. В правое окно (Query) вставить любой из запросов из queries.txt
4. Нажать Run.

Почему MongoDB: Использование встроенных массивов и $lookup позволяет эффективно 
моделировать связи без сложных JOIN'ов, как в SQL.
